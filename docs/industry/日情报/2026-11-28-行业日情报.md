## 今日情报

### 【[新] 阿里千问办公「AI教育灯塔计划」首批试点落地杭州富阳：区教育局签约，为 65 所学校探索教研驾驶舱；两所小学用通用 Agent 完成五育画像与班级错题库】

- 事件：**芥末堆 11-27 10:11（GMT）与多知网同日发布**：**千问办公"AI教育灯塔计划"在杭州市富阳区启动实施，富阳区教育局作为首批签约示范单位**，合作导向被写为"AI 进校园，不是应对考试，而是服务于学生的全面成长和教师的专业发展"。**第一层是区域教研管理**：探索搭建**覆盖全区 65 所学校**的教研驾驶舱，目标是区级教研员可查看各校各学科动态数据，"为教研指导和资源配置提供参考"，并明确"不是给学校排名次"。**第二层是学校日常教学管理**：**富阳新民小学**（乡镇农村小学）将家访归类、五育评价、教师四维诊断等校园规则配置进千问办公后，**20 多万条评价记录自动完成五育归类、一师/生一画像报告、1000 多条家访记录一键生成**（此前写一份全校家访总结要翻 1000 多条记录、耗时数周）；**春江中心小学**教师把错题**拍照批量上传**，系统自动挑出高频错题、标注知识点和错因，**班级错题库与学生个人档案同步积累，从作业布置到二次过关全程留台账，家长自动收到回执**，学情整理由数小时压缩到十几分钟。**第三层是期末复习**：区教育局基于千问办公多人工作台搭建"复习综合管理工作台"，学生端按薄弱点生成个性化复习路径，教师端看每道题正确率与复习完成情况，并面向一线教师开展 AI 应用培训。**背景**：千问办公是面向组织使用的企业级 Agent 产品，以**统一账号与权限管理**把教师个人摸索的用法沉淀为学校/区域可复用的工具；**"AI教育灯塔计划"2026-09-23 在云栖大会上发起**，面向全国大中小学，**首批签约单位超 100 家**——含北大、浙大、复旦、东南、同济、南开等高校，以及北京、上海、深圳、杭州、重庆、西安、武汉等地区域教育主管部门与中小学；同期发布"企业上下文"与 Agent 托管能力，支持学校整合信息、配置权限、部署 Agent。富阳区为**全国第二批人工智能试点区**，区教育局为**教育部人工智能助推教师队伍建设试点单位**。
- 来源：[“AI教育灯塔计划”首批试点落地杭州富阳，AI教研覆盖全区65所学校（芥末堆，2026-11-27）](https://www.jiemodui.com/N/139675.html)；[千问办公“AI教育灯塔计划”落地杭州富阳，AI走进教研与教学管理（多知网，2026-11-27）](http://www.duozhi.com/industry/insight/2026112719011.shtml)（T2-行业报告/媒体，两条均为企业供稿性质，功能描述为企业自述）；[千问办公启动“AI教育灯塔计划” 首批签约学校等超100家（新浪财经，2026-09-23）](https://finance.sina.com.cn/roll/2026-09-23/doc-inisvcpx6058999.shtml)（T2，灯塔计划起点口径）
- 对学科网的影响：
    - 威胁：**通用办公 Agent 把进校切口从"教师工具"上移到"区域教研管理"，这是本期最重要的结构变化**。对照 11-26 期腾讯 WorkBuddy 整州覆盖黔西南（775 所中小学、近 5 万教师 100% 开通）、11-27 期正元智慧×实在智能"智慧校园智能体底座"——**平台方正在争夺的不是单个教师的使用习惯，而是区县教育局的"AI 底座"位置**。一旦区县把账号体系、权限与数据出口交给通用 Agent，学科侧采购就要绕开已有入口，或被要求"接入"而非"选型"。**千问办公与观察池中的"钉钉教育"同为阿里系，产品关系与团队归属待核实，本期不作合并判断**。
    - 威胁：**春江中心小学那条链路——"错题拍照批量上传→高频错题→知识点与错因标注→班级错题库+个人档案+家长回执"——在功能上与我方 e卷通/学情产品重合，但它是在没有题库厂商参与的前提下用通用 Agent"配置规则"实现的**。这意味着"题库体量"作为壁垒的叙事进一步被削弱（与 11-27 期卓越睿新"知识图谱占收入 59%"同向）：**客户开始认为"错题库"是可以搭建的，而不是必须购买的**。我方必须把价值锚点从"有题库"移到"题目来源可追溯、命题与评分可复核、课标对齐可验证"。
    - 机会：**千问办公自己划出的边界很清楚——"AI 提供线索，怎么教、怎么评，仍然由教师做判断""不是给学校排名次"**。这与我方"教研先行、评价权在教师"的立场同向，可作为对外口径的共同基础；同时通用 Agent 缺的正是**学科教研内容（命题质量、课标对齐、教研方法）**，我方在富阳这类"已签约通用 Agent"的区县里，位置应是**内容与教研供给方**，而不是再卖一套平台。
    - 信息：⚠️ "65 所学校""教研驾驶舱"是**探索搭建目标**，无验收数据、无采购金额、无招标记录；两校数据（20 多万条评价、1000 多条家访）为**单校自述**，无第三方核验；"灯塔计划 100+ 签约学校"为 9 月口径；**不得据此推断阿里已在四川、浙江等地形成区县级采购**。

### 【四川省教育厅印发"四川AI助教"应用推广通知：省级统一保障、统一账号、全免费，应用纳入教师培训与校本研修"必修内容"，并遴选区域/学校/教师案例】

- 事件：**11-27 08:14，四川省教育厅官网发布《关于做好"四川AI助教"应用推广工作的通知》要点**：要求各地各校把"四川AI助教"推广应用纳入重点工作统筹部署、突出应用实效、加强教研指导、开展分层培训。**"四川AI助教"是"天府云教"核心应用之一，专为全省中小学教师打造，由省级统一保障、统一平台、统一账号、全免费使用**。**应用场景被逐项点名**：课前——教学资源准备、教学设计、课件设计、学习活动设计、**分层作业设计**、实验方案设计；课中——情境创设、课堂互动、标准语音示范、虚拟仿真实验、个性化学习协作；课后——**智能出题组卷**、课堂智能分析。**制度性要求是最关键的部分**：各地各校要将应用**纳入教师培训、校本研修、名师名校长工作室建设等必修内容**，并纳入全省中小学教师人工智能素养全覆盖培训统筹安排；依托"天府云教"联盟以**送培到校、线上辅导、结对帮扶、跟岗研修**扩大培训覆盖面；教育厅将依托四川中小学智慧教育平台**遴选应用成效明显的区域、学校和教师优秀案例**。

- 对学科网的影响：
    - 威胁：**从"上线"到"必用"只用了两个月**。9-28 期已记录"四川AI助教"正式上线（芥末堆，面向全省中小学教师免费开放），本期通知把使用**制度化**：进教师培训必修、进校本研修、进名师工作室，再以"送培到校、结对帮扶"扩大覆盖面——**免费工具的渗透不再靠产品力，而靠考核与培训制度**。其点名的"分层作业设计、智能出题组卷、课堂智能分析"三项，正压在教师端最刚性的付费场景上。
    - 威胁：**9-28 期的判断需要修正一半**——当时认为"政府侧不具备生产高密度教研资产的能力，我方可以成为省级助手的内容供给方"。**本期通知显示供给路径是"省级平台 + 天府云教联盟 + 自有培训体系"，通篇未提外部内容供给方**，说明**省级自建路线的供给窗口正在收窄**；若仍要进入，需要核实"天府云教"及其升级项目的采购清单与入围方式，而不是等待被动招募。
    - 机会：**"送培到校、结对帮扶、跟岗研修 + 案例遴选"是明确的服务型需求，且是省级自己写进通知的**。我方 AI 研修与教研服务（教师评审团、课例打磨、应用案例包装）可直接对接培训与案例征集这两个环节，这是**不依赖产品替代**的切入面。
