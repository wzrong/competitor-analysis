## 他们的进攻话术（已知）

**老话术（沿用）：**
1. 「我们有亿级学生数据，推题精准，教师版是C端数据的B端延伸」
2. 「拍照组卷很方便，手机就能用，免费功能很多」
3. 「作业帮品牌学生都知道，老师认可度高」

**Q3 新增话术（Z100/硬件背景下可能出现）：**
4. 「我们刚发布了 Z100 学习机，AI+本地化，技术实力很强」
5. 「作业帮有亿级用户，平台规模大，不会倒」

## 我们的反制

| 他们说 | 我们回 |
|---|---|
| 「亿级学生数据，推题最精准」 | C 端学生数据确实多，但这个数据底座正在松动——豆包爱学 7 月已挤入 AppStore 教育榜前 20，作业帮从 1 月第 2 位滑到 7 月第 7 位，用户在向大模型平台迁移。数据飞轮在减速，B 端精准度的优势会随之弱化。 |
| 「拍照组卷方便，免费功能多」 | 拍照识题很便捷，我们承认。但用于学校正式考试，题目版权和来源很关键——C 端用户上传的题目版权杂，不适合出正式考卷。学科网 3000 万题都经过审校，出正式考试更安全。 |
| 「作业帮品牌学生都知道」 | 学生认知和教师选工具是两码事——老师选备课平台看的是资源深度、阅卷能力、教研支持，不是学生知道这个品牌。学科网在 4.5 万所学校的口碑，是老师圈里的真实口碑，不是学生层面的品牌认知。 |
| 「Z100 学习机技术强，说明实力好」 | Z100 是 C 端学习机，面向家庭，不是 B 端教师工具。作业帮这次发布的是硬件产品，说明资源正在向 C 端硬件倾斜，教师版的功能迭代和服务投入短期内不是优先级。 |
| 「作业帮规模大，不会倒」 | 规模大不等于 B 端稳定。C 端业务受大模型冲击是整个行业正在发生的事，作业帮当前的战略重心已经移向 C 端硬件防守。B 端教师版不是他们现在的核心投入方向——选一个对 B 端教学平台专注了 22 年的合作伙伴，续约和服务保障更可预期。 |

## 主动引导话题（本次新增，适合与客户开启的话题）

以下话题可以由我方销售**主动开启**，引导客户自己发现风险：

- 「您用过作业帮教师版吗？听说他们最近主要在做 C 端学习机，教师版这块您感觉更新频率怎么样？」
- 「豆包爱学最近涨得挺猛的，听说很多学生在往那边迁移，您学校的老师有没有感受到？」
- 「选备课平台，三年后续约是关键。您有没有了解过作业帮的 B 端合同和服务体系？」
- 「他们的题库有 1500 万道题，学科网有 3000 万。两个平台您有没有同时试用过，差异在哪？」

---

## 引导问题（让客户自己发现对方弱点）

- 「老师用作业帮出的题，是否适合直接用于期中期末的正式考试？还是主要用于平时练习？」
- 「作业帮教师版有没有阅卷功能？批改后的数据能形成学情报告吗？」
- 「教研组集体备课，作业帮有没有协同功能和校本题库？」
- 「老师评职称、做教研，作业帮有没有研修和学分体系？」
- 「如果明年作业帮的 B 端产品方向调整，或者减少对教师版的投入，对学校有什么影响？我们提供 22 年稳定的合作关系。」

---

## 绝对不要说的话

- ❌「作业帮快要不行了」（有夸大之嫌，会失去可信度；要说的是"B 端战略重心在调整"）
- ❌「他们的数据是假的」（C 端亿级用户是真实的，攻击会踩雷）
- ❌「拍照组卷没用」（这个功能对很多教师有真实价值，要承认然后转移到版权和准确性问题）
- ❌「比作业帮便宜」（价格不是我们的核心优势，不要打价格战）
