### ⭐ 1. Stripe 以约 75 亿美元收购 OpenRouter

**核心观点**：支付巨头 Stripe 确认收购 AI 模型路由/网关平台 OpenRouter，报道称交易价约 75 亿美元（Bloomberg/NYT 等，Stripe 史上最大收购），远超其 5 月约 13 亿美元的估值。OpenRouter 通过单一 API 让开发者路由 80+ 供应商的 400+ 模型，日均处理超 10 万亿 token、服务超 1000 万开发者。Stripe 把它定位为"AI 经济基础设施"——从支付处理延伸到 token 路由与算力支出管理。这标志着 AI 推理的"分发/路由层"首次被主流金融基础设施正式定价，模型供应商与开发者之间的这一中间层，战略价值被资本重估。

[来源](https://www.ithome.com/0/991/918.htm) · [来源](https://www.zhiding.cn/ai-applications/2026/0820/3196924.shtml) · [来源](https://indianexpress.com/article/technology/artificial-intelligence/stripe-to-buy-openrouter-why-are-ai-model-gateway-platforms-gaining-importance-10842205/)

### ⭐ 2. Google 发布 Gemini 3.7 Flash：价格减半，主打编程与智能体

**核心观点**：距 3.6 Flash 仅三周，Google 推出 Gemini 3.7 Flash，定位"迄今最擅长编程与智能体任务的主力模型"。输入 0.75 美元/百万 token、输出 3.75 美元/百万 token，价格近乎减半。基准显著提升：DeepSWE v1.1 从 49.0% 到 65.3%、FrontierCode 1.1 从 34.4% 到 43.6%、AutomationBench 从 17.0% 到 30.4%。Google 同时透露高端 Pro 系列放缓迭代节奏。信号：模型竞争正从"旗舰堆料"转向"快速、便宜、任务专精"，Google 以降价加卷 Agent/编程的方式贴身争夺开发者。

[来源](https://www.thepaper.cn/newsDetail_forward_33813023)

### ⭐ 3. Anthropic 二季度收入据报首超 OpenAI，传考虑天量 IPO

**核心观点**：多个信源显示 Anthropic Q2 初步收入超 115 亿美元（去年同期 7.87 亿），首次季度收入反超 OpenAI；Bloomberg 报道 Anthropic 正考虑一场可能比肩或超过 SpaceX 纪录的 IPO，或在 8 月底前公开申报（5 月已融资 650 亿美元、估值 9650 亿）。叠加 Claude 用量研究估算节省 2.7 万亿劳动力成本、企业数据保留政策调整、合资公司 Ode 首次收购，Anthropic 正从"技术领先"全面转向"商业化铺开"。AI 竞争进入收入与资本市场的正面比拼阶段。

[来源](https://www.capital.gr/diethni/4011630/anthropic-stoxos-na-isofarisei-i-na-xeperasei-to-rekor-tis-ipo-tis-spacex-bloomberg/) · [来源](https://www.sohu.com/a/1065056021_122014422)

### ⭐ 4. DeepSeek Harness rc.8：补全多模态与子 Agent 协作

**核心观点**：DeepSeek Harness（DSH）发布 v0.1.0-rc.8，约 14 项更新。核心是补全多模态（原生图片请求、输入框 @ 引用文件/会话，纯文本模型用 OCR/像素扫描兜底）与子 Agent 协作（Claude Code、Codex 可作为 Profile Bundle 安装并被调用，Codex 支持非交互权限与多命名实例）；web_search 支持并发查询。DSH 开源仅约一周 GitHub 已破 15.2 万 star。信号：DeepSeek 的 Agent 框架正从"自家工具"走向"通用 Agent 工作环境"，把模型、文件、搜索、终端、第三方 Coding Agent 收进同一工作流。

[来源](https://www.pingwest.com/w/316594) · [来源](https://eu.36kr.com/zh/p/3947115501845891)

### ⭐ 5. 论文 OmniScientist：全模态、全学科的 AI Scientist

**核心观点**：现有 AI Scientist 已能跑通"假设→代码→论文"的完整工作流，但覆盖的是"流程"，缺少对"多模态原始证据"的通达。OmniScientist 提出端到端、全模态的 AI 科学家，用自治 Agent 与"生命周期感知"直接从异构原始证据做多学科研究，提升证据驱动的发现能力。这与 Claude 自主设计蛋白质、CMU 的数学发现流水线同向——AI 正在从"助手"变成"主研究员"。

[来源](https://huggingface.co/papers/2608.16590) · [arXiv](https://arxiv.org/abs/2608.16590)

### ⭐ 6. 论文 Co-RL：推理从多智能体 RL 的"同伴激励"中涌现

**核心观点**：RL 提升推理能力目前高度依赖可验证的 ground-truth 监督。Co-RL 用协作式多智能体强化学习，以"同伴提供的奖励"替代外部标注，在文本与视觉任务上均实现无监督的推理能力提升。这为"没有标准答案的开放问题"提供了一条强化学习路径，是无监督推理方向值得关注的一步。

[来源](https://huggingface.co/papers/2608.13947) · [arXiv](https://arxiv.org/abs/2608.13947)

## 灵感种子

> 以下是今日简报中值得进一步思考的灵感种子。

**AI 的"分发层"被主流金融基础设施整合**：Stripe 收购 OpenRouter，把 token 路由并进支付基础设施。值得深挖：当支付层掌控了 token 路由，模型供应商与开发者之间的议价权会如何重新分配？会不会出现"AI 时代的 Stripe 税"，成为新的利润沉淀点？

**价格信号开始分化：从"全面降价"到"按任务分层定价"**：Gemini 3.7 Flash 价格减半主攻编程/Agent，DeepSeek 与国产厂商却在涨价、引入峰谷分时计价。值得思考：推理成本曲线还能往下走多久？"便宜"到底是一种能力优势，还是一种烧钱换规模的策略？

**无监督推理的强化学习路径，与 RL 的安全代价形成对照**：Co-RL 用同伴奖励替代 ground-truth，可能打开"没有标准答案"的开放问题的 RL 空间；而 OpenAI 刚因安全风险暂停前沿 RL 训练、并披露约 20% 的监控算力开销。值得深挖：RL 的边界、代价与收益正在被同时重新丈量，这会不会重塑下一阶段的训练路线之争？

**具身智能的资本定价远超营收兑现**：宇树科技上市首日暴涨 629%、王兴兴成 90 后首富，但行业整体仍处于商业化早期。值得关注：当具身智能的资本热情与真实营收之间的落差持续拉大，泡沫与拐点如何判断？"数据底座商品化"（如昨日五一视界开卖数据方案）是否是更早兑现的环节？
