## 深度阅读推荐

### ⭐ FlashProve：用密码学证明这条回复真的来自这个模型

用户向模型提问时，没有任何办法确认回答出自他选的那个模型，而不是路由服务为省钱偷偷换掉的另一个，也不是被攻击者篡改过的 token 流。Anthropic 研究团队把这称为「可证明推理」（provable inference），并给出了一个可运行的原型 FlashProve。

做法是 zkSNARK：模型提供方先对某个模型作出承诺，之后每条回复附带一份几 MB 的短证明，用户在 CPU 上几秒内就能验完，证明本身不泄露任何权重信息。性能数字是这样的——对 400B 参数的混合专家模型（Llama 4 Maverick，4 bit 量化），单张 H100 每秒能生成 100 多个 token 的证明，1024 token 的请求对应约 19MB 证明；代价是 **70 至 95 倍**于 vLLM 处理同长度提示的 GPU 时间。

团队同时开源了代码、Lean 形式化证明与协议文档（Apache 2.0），并主动声明这是中间进展，不是完成品。他们列出的用途里，最值得注意的不是消费者信任，而是独立评测方可以确认「我测的就是线上正在服务的那个模型」，以及监管可以借此核对「部署节奏承诺」是否被遵守。

**核心观点**：这件事把「模型身份」从营销话术变成可验证的技术属性。一旦验证成本被接受，路由服务、评测机构和审计方之间的信任关系就要重写——「你用的是哪个模型」这句话第一次有了标准答案，而不是靠合同和品牌背书。

来源：[Anthropic（含完整技术报告）](https://www.anthropic.com/research/provable-inference) · [Techmeme](https://www.techmeme.com/)

### ⭐ GPT-6 Astra 一周做完一台硬件：外壳、布线、固件都是它写的

OpenAI 硬件团队用 GPT-6 Astra 设计了一台让用户直接和 Codex 编码智能体对话的设备，作为一个「副项目」在**不到一周**内完成。按官方说法，Astra 包办了外壳设计、PCB 布局（含器件选型与走线）、固件和用户界面；代工厂在不到一个月里做出了小批量原型。

返工的地方很有信息量。Astra 并不总是考虑制造约束、公差和装配细节，因此来回改了几轮才达到可生产状态。OpenAI 同时放出了 CAD 能力的分数：新出现的「内部模型」在 BenchCAD 2.0 上拿到 **0.875**，而 GPT-6 Astra 在最高推理档只有 0.594——这个测试考的是模型能否重建三维零件与装配体、识别 PCB 上的连接关系。

公司还说硬件团队在机器人、算力基础设施等领域普遍使用 Codex 与 ChatGPT 做 CAD 模型、工程图与仿真，相关 token 用量自 2 月以来增长 **23 倍**；OpenAI 自己在造的那台设备，据说介于 AI 音箱和智能手机之间。

**核心观点**：这条最有价值的部分不是「一周」这个数字，而是失败模式。AI 把设计推到「能出图」只花了一周，剩下的时间全花在公差、装配与工艺上——也就是说，硬件设计的瓶颈正从绘图能力转移到制造知识。谁能把工厂的经验喂进模型，谁才拿得到那 70% 的时间红利。

来源：[The Decoder](https://the-decoder.com/openai-says-gpt-6-astra-designed-a-hardware-device-from-scratch-in-under-a-week/) · [OpenAI](https://openai.com/index/accelerating-engineering-for-the-physical-world)

### ⭐ 斯坦福数了 50 条「模型结论」：44% 已经过期，平均寿命 15.7 个月

Owen Queen 与 James Zou 把 50 条被广泛引用的大模型结论，放到 8 家开发商、2024 年 7 月至 2026 年 9 月发布的 20 个模型上重测。结果是 **44% 已经失效**，另有 34% 明显减弱，仍然成立的只剩 16%，还有 6% 变得更强。在有估算过期时间的 22 条里，平均寿命 15.7 个月；一年内过期 16%，两年内 39%。

失效最快的是「模型做不到什么」。9 条推理类结论里有 5 条过期且无一变强，包括数 strawberry 里的字母、陌生进制算术、长上下文中间信息丢失、以及被用户反驳就放弃正确答案。研究者的解释很直接：这类错误有明确的对错，等于给开发者一个可训练的目标。

活得久的是偏好与倾向类：模型偏爱自己的答案、对接收与拒稿论文打相近的分、被医学摘要里的措辞带偏；谄媚、政治倾向偏左、开放问题的回答高度雷同、随机数分布不均，也都还在。一个具体案例是引用伪造——2023 年 GPT-3.5 编造了 55% 的参考文献，如今 GPT-6.1 Sol 是 0%、Claude Sonnet 5.5 是 1%，但同期的 Qwen3.7-Flash 仍有 **69%**。

**核心观点**：这项研究真正提出的是一条工程规范：关于模型的经验结论应当被写成「某模型在某时点的观察」，并注明版本、日期、提示词与分析代码。对做评测、写选型报告、维护内部知识库的人来说，这意味着任何「模型不擅长 X」的判断都要带上时间戳，否则它会在一年内悄悄变成错误答案。

来源：[The Decoder](https://the-decoder.com/rapid-llm-development-is-outrunning-the-research-meant-to-explain-it-study-finds/)

### ⭐ DeepMind 给 Antigravity 装上化学技能：一小时的活，原来是几天

DeepMind 为 Google Antigravity 发布了一套化学信息学技能（Cheminformatics Skills），底层接的是开源化学工具 RDKit 与策展好的数据库。分工很清楚：语言模型负责流程编排、数据库导航与科学推理，确定性的化学工具负责计算分子性质。

官方演示选的是一段真实药物化学工作流——刚性化改造（rigidification）。以肺癌靶向药克唑替尼为起点，智能体先在文献里检索数千种化合物，几分钟内过滤掉缓冲液和溶剂并记录来源；随后做匹配分子对分析（MMPA），验证「环化降低可旋转键、提升活性」这一假设，再用不同特征集与架构训练多个活性模型，并用骨架切分评估分布外表现。

最后它基于学到的规律设计新的大环化合物，给出多条合成路线，甚至画出电子推动箭头来解释环化机理。整条链路在一个小时左右完成，而官方给出的传统口径是**单次迭代需要数天**。DeepMind 同时开放了 1 万名科学家的六个月最高额度免费申请。

**核心观点**：这条的意义不在「AI 会做药」，而在它把「专家经验」拆成了可执行的技能包：检索、清洗、配对分析、建模、提出假设。真正被自动化的是那些重复的中间步骤，留给化学家的是判断哪一个假设值得做实验——这也正是官方自己强调的边界：计算结果只是可检验的假设，不是成品药。

来源：[Google DeepMind](https://deepmind.google/blog/agentic-cheminformatics-with-google-antigravity/) · [IT之家（中文整理）](https://www.ithome.com/1/021/858.htm)

### ⭐ Revolut 把编码智能体换成自托管 GLM，推理成本砍掉约九成

据 The Register，英国金融科技公司 Revolut 用不到一年时间把 AI 编码的推理成本压低了约 **90%**，做法是把默认工具从 Claude Code 这类商业产品换成自托管的 GLM 开源模型。

这条之所以值得单独拎出来，是因为它把前一日的争论又推了一步。11 月 3 日的简报里，高盛刚把 AI 编码工具从交易员手里收回去，理由是风险管理；同一天还有消息称 OpenAI 漏洞赏金与安全冲刺加码。Revolut 给出的是另一种答案：不是不用，而是把模型搬进自己的机房，用开源权重换单价与合规可控。

同一天的另一条消息正好构成对照：英伟达要求部分云客户减少来自中国公司的业务，并披露最终用户身份。算力放在哪里、模型归谁所有，正在同时被成本与出口管制两头拉扯。

**核心观点**：企业级 AI 的成本结构正在从「按席位订阅」转向「按 token 自建」，而驱动因素不只是价格——数据驻留、审计要求和供应链政策都会把人往自托管推。对模型厂商来说，这意味着一部分最优质的客户会以「开源权重 + 私有算力」的方式离开订阅制。

来源：[The Register](https://www.theregister.com/ai-and-ml/2026/11/03/british-fintech-revolut-slashes-ai-coding-costs-10x-by-cutting-out-claude-and-going-self-hosted/5307345) · [Techmeme](https://www.techmeme.com/)

### 量子位评 Orilo：纯语音 Personal Agent 卡在「一低两高」

这篇实测把当下 Personal Agent 的困境总结成三个字：任务低频、对齐成本高、token 成本高。为了订一张机票跟助手来回对齐半小时，不如自己点两下；每次调用都要走复杂工具链，成本随对话线性上升。

## 灵感种子

**「可证明」会成为模型服务的一项商品属性。** FlashProve 的代价是 70 到 95 倍的 GPU 时间，这不是一个小数字，但它换来的是「你付钱买到的确实是这个模型」这一句话。可以设想两条商业路径：一是只在合规敏感场景加价出售证明，二是把证明做成路由服务的默认能力。哪条先跑通，取决于审计和监管谁先提出要求——而现在金融、医疗、政府这三个最需要它的行业，恰恰还没有人提出。

**研究结论的保质期是 44%，那知识库的保质期是多少？** 斯坦福这项研究最有操作价值的部分不是比例，而是分类：关于「模型做不到什么」的结论死得最快，因为它们有明确的对错，等于给训练提供了目标；关于「模型的偏好」的结论活得最久，因为它们没有被当作问题去修。这意味着任何一份内部评测报告都需要带时间戳与版本号，否则半年后它就在误导决策。

**模型的可迁移性正在变成选型的第一变量。** 华为云两款盘古模型一个月内停售下线，Revolut 把编码智能体换成自托管 GLM 省下九成成本，英伟达又要求云客户减少中国业务——三件事指向同一个问题：这个模型/这套算力，换掉要付多少代价。过去选型看能力与价格，现在还要看退出成本，而退出成本几乎没人认真算过。

**硬件设计的瓶颈正在从「画图」挪到「制造」。** Astra 一周做完原型，剩下的返工全在公差、装配与工艺上。这一层知识目前只存在于工厂的老师傅和供应商的报价单里，不在任何公开数据集里。如果 AI 真的要吃下硬件设计，下一个高价值数据资产可能是产线日志与工艺参数——谁先拿到，谁就能把「一周出图」变成「一周出货」。
