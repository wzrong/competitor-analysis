### ⭐ Kimi K3 权重今日正式开放：史上最大开源模型完整可用

月之暗面（Moonshot AI）于7月16日发布 Kimi K3 后，今日（7月27日）正式对外开放完整的 2.8万亿参数模型权重。

**模型亮点：**
- **规模**：总参数 2.8T，MoE 架构，896 个专家，每个 token 激活 16 个专家（等效活跃参数约 50B）
- **创新架构**：Kimi Delta Attention（KDA，可实现高达 6.3x 解码加速）+ Attention Residuals（提升 ~25% 训练效率）
- **原生多模态**：内置视觉输入，1M token 上下文，全量思考模式（always-on thinking）
- **开放条件**：权重免费下载，API 已上线，支持免费层级使用

K3 发布时震动华尔街——Alphabet 和 Meta 股价当日分别下跌 2% 和 3%，投资人称之为"Kimi 时刻"。国内市场影响同样显著：智谱 AI 股价因市场担忧 K3 与其产品定位高度重叠，在解禁压力叠加下从历史高位暴跌逾 66%（随后反弹）。

**核心观点：**
- 开源前沿模型的参数规模已突破传统认知，但"2.8T 总参数、50B 活跃参数"的设计表明：真正的可用性门槛不在于权重获取，而在于推理成本——完整部署需要超大规模内存和算力，绝大多数组织短期内仍难以自主运行。
- Kimi K3 是中国开源模型持续缩小与美国闭源模型差距的最新证据，也是本轮开源攻势在规模上的新纪录，开源生态的"重量级玩家"正在形成。

### ⭐ Simon Willison：LLM Token 地下转售市场深度调查

Simon Willison（Django 联合创始人）分享了对 LLM token 转售"中继市场"的深度调查。该市场以中国为核心，转售商通过以下方式低价获取 API 访问权：

- 批量滥用各大模型厂商免费试用额度
- 代理未受保护的企业支持机器人
- 使用盗刷信用卡或拒付攻击

这些 API key 汇集成池，通过开源代理产品 [one-api](https://github.com/songquanpeng/one-api) 和 [new-api](https://github.com/QuantumNous/new-api) 对外转售，折扣可达30%-70%。买家动机包括：廉价 token、绕过地理限制、以及收集数据用于模型蒸馏。

**核心观点：**
- 这一生态系统的存在对独立开发者公开 LLM 驱动应用构成了现实威胁——不仅要防止普通用户滥用，还要面对整个"专业寻找无保护端点"的有组织社区。
- Willison 呼吁 LLM 厂商尽快为 API Key 提供严格的周期性支出上限，而非依赖事后封禁。
- 这一现象的更深层含义：LLM 定价策略本身的地区差异与访问限制，正在主动制造套利空间。

来源：[Simon Willison](https://simonwillison.net/2026/Jul/26/relay-market/) | [原始调查报告 (Vectoral)](https://vectoral.com/blog/token-relay-market)

## 灵感种子

> 以下是今日简报中值得进一步思考的灵感种子。

**🌱 "最大"不等于"最可用"：开源模型的推理成本墙**

Kimi K3 权重开放，但 2.8T 参数对大多数组织意味着数百万美元的推理基础设施。开源的边界正在从"可获取"转移到"可负担"。未来的开源生态是否会形成新的分层——权重开放，但能真正运行的只有少数超大规模玩家？这对"开源民主化"的叙事是挑战，还是一种新的合理分工？

**🌱 Token 转售市场是 AI 定价策略的一面镜子**

LLM 地下转售市场的存在，本质上是厂商定价逻辑与用户真实支付意愿之间的套利空间。当地区差异、访问限制制造了足够大的价差，市场自然会填充这个空隙。这让人想问：哪些 AI 产品团队正在有意识地设计"反套利"的定价架构？还是大多数人把这个问题留给了风控团队？

**🌱 Remote Labor Index：我们应该追踪什么作为 AI 能力的真实温度计**

从 2.5% 到 16.1%，六个月6倍。但 Remote Labor Index 本身是否足够全面？它测量的是计算机操作任务，而非复杂推理、创意生成或跨域协同。不同任务类型上 AI Agent 的能力曲线斜率可能差异巨大——哪些指标最能预示"下一个质变点"的到来？
