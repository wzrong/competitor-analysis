# 学科网情报系统 · 每日情报概要 | 2026-11-19

> 一句话判断：AI教学工具的渠道整合与通用入口竞争并行，学科网应以可授权、可审校的学科内容和测评能力应对，同时提前核对四川教辅准入要求。

## 今日重点

1. **战略竞争信号：媒体报道学大控股书舟，取得作业与试卷分析产品入口。**多知网11月18日报道，学大全资子公司于10月22日成为书舟教育51%股东，涉及「作业学伴」与「试卷分析平台」。这是今日落盘的既有交易报道，并非今日新发生交易；本轮未独立回查工商登记，交易对价、产品并入方式及学校覆盖尚未核实。**对学科网的含义（分析判断）**：作业辅导、试卷解析与学情分析存在场景重叠，宜关注其渠道整合进展及内容授权合作可能，不能据此认定已形成低价替代或规模化收入。
   来源：[T2-行业报告/媒体, 多知网, 2026-11-18](http://www.duozhi.com/industry/insight/2026111818988.shtml)。

2. **重要政策约束：四川教辅新规12月5日施行，今日补录官方依据。**川教发〔2026〕19号11月5日成文、11月6日发布，有效期2年；明确出版资质、教材授权、目录选用及内容质量要求，鼓励将义务教育教辅纳入政府采购。省目录外免费教辅须使用前至少6个月报省备案、至少2个月报省内容质量把关。**对学科网的含义（分析判断）**：相关出版合作须核对主体、版权、版本及备案提前期；可跟踪地方免费教辅项目，但政策未披露新增拨款、供应商或订单，不能外推为全部数字题库、AI工具的统一准入规则。
   来源：[T1-公开可查证, 四川省教育厅等三部门正式正文, 2026-11-06](http://edu.sc.gov.cn/scedu/cjfwjb/2026/11/6/c1bb715de43747538047c28141b2b32f.shtml)；[T1-公开可查证, 四川省教育厅官方解读, 2026-11-06](http://edu.sc.gov.cn/scedu/c100561/2026/11/6/ae06861e0581484f8f196d14211c44bf.shtml)。

3. **教师入口信号：腾讯WorkBuddy商业化口径获媒体报道。**IT之家11月18日据腾讯分析师会公开分享报道，最近七天收入年化折算超过5亿美元。**对学科网的含义（分析判断）**：通用工具的商业化进展值得纳入教师端竞争观察，可用真实备课任务检验学科内容、解析与审校的差异价值。七天年化数不等于已确认全年收入，也不能证明教育公益版永久免费或教师场景商业化效果；客户覆盖和Token口径不用于推算教育收入。
   来源：[T2-行业报告/媒体, IT之家转述腾讯公开分享, 2026-11-18](https://www.ithome.com/1/029/110.htm)。

## 建议关注

- 对拟进入四川学校的教辅合作，优先核对12月5日施行节点、出版授权和免费项目备案路径；采购机会以后续正式公告为准。
- 关注学大产品整合和教师工具实际使用变化，以内容来源、解析质量、教师复核和授权边界比较方案。行业材料中的学习平板降幅统计机构未明、赶考状元企业供稿备案号尚未官方核验，不纳入已核实重点；教智1号承接昨日已知事件，不重复计为新发布。
