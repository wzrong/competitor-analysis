# 学科网情报系统｜每日情报概要

日期：2026-11-25（Asia/Shanghai）

## 一句话判断

教师端产品继续整合为统一工作台，区域平台与隐私合规同步提高内容服务的接入要求；学科网应优先评估跨场景体验、资源接口及可验证的合规能力。

## 今日重点

1. **九章老师 2.0 将教学能力整合至统一工作台。** 11月24日媒体刊发的企业发布稿介绍题库组卷、学科资源、班级资料、个人云盘与教师应用五类能力，今日行业模块已落盘。对学科网：备课、资源与组卷的连续体验值得优先评估，比较指标可包括检索质量、改编效率和使用过程留痕。此次增量是产品整合，不能写成新模型发布；题量、服务教师规模均为企业自述，未独立核验，本概要不作规模对比。定价与商业化方式尚未披露，也不能从发布稿未列某功能推断产品没有该能力。来源：[T2-行业报告/媒体, 芥末堆转载企业发布信息, 2026-11-24](https://www.jiemodui.com/N/139671.html)。

2. **86 款移动应用被通报，教育产品须关注隐私与儿童信息处理。** 今日行业模块核对的11月24日通报转述涉及第三方 SDK 披露、单独同意、注销与撤回同意，以及不满14周岁未成年人专门处理规则等问题，名单包含教育类产品。对学科网：可将 App 与小程序的数据流、SDK 清单和儿童信息规则纳入产品自查及进校材料准备。此为媒体转述监管通报，不代表教育行业整体违规比例，也不据此认定学科网产品存在问题。来源：[T2-行业报告/媒体, DoNews转述监管通报, 2026-11-24](https://www.donews.com/news/detail/1/6780132.html)。

3. **文山州教育体育服务平台上线，区域集成平台进入应用阶段。** 11月24日地方媒体报道平台上线，覆盖课堂诊断、观摩与跨区域教研等应用；今日行业模块补录。对学科网：关注优质资源、教研服务与既有区域平台的接入机会，而非仅以独立工具推介。报道未披露总投资、完整应用系统清单和技术底座，不推算采购金额或认定新增商机。来源：[T2-行业报告/媒体, 文山新闻网, 2026-11-24](http://www.wsnews.com.cn/wsnews_kj/2026/11-24/vrdBzQwk.html)。

## 建议关注

- **验证校内部署的实际成本与效果。** 行业与 AI 简报共同收录文心5.5 Flash Preview于11月24日开放权重的信息，合并为一项信号；采用 Apache 2.0 许可不等于学校现有硬件即可运行，也不保证数据处理自动合规。部署前需实测硬件成本、并发、教学任务质量与数据边界。来源：[T1-公开可查证, 百度模型权重仓库, 2026-11-24](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)；[今日 AI 简报](https://comp.wzrong.me/ai-briefings/2026-11-25-AI每日简报/)。
- **区分科研立项与采购需求。** 河南科研实验项目通知今日入库，属一般通知，落款11月20日、官网11月24日发布，实验周期三年；正文未披露采购预算，附件明细尚未核读，不能认定为 AI 采购或具体试点清单。来源：[T1-公开可查证, 河南省教育厅办公室, 2026-11-24](http://jyt.henan.gov.cn/2026/11-24/3451443.html)。
