# 每日情报概要｜2026年8月21日

> **一句话判断**：今天的公开信号主要来自 GSE2026 收官与科大讯飞半年报，AI 教育竞争继续向“教师工具 + 智能批阅 + 学情数据 + 区域方案”收拢；学科网应把资源、题库、评价、研修与接口能力做成可被区域平台和大厂生态直接接入的标准件。

## 今日重点

### 1. 科大讯飞半年报显示智慧教育收入微降，G 端主动收缩

科大讯飞 2026 年半年度报告显示，营收 116.23 亿元、归母净利润 -2.04 亿元，研发投入 30.07 亿元；分业务看，智慧教育收入 34.90 亿元，同比微降 1.16%，G 端业务同比 -2.65%。公司明确“做强 C 端、做深 B 端、优选 G 端”，说明传统项目型业务在收缩，但 B 端产品化和 C 端硬件仍在加码。[查看行业日情报](https://comp.wzrong.me/industry/%E6%97%A5%E6%83%85%E6%8A%A5/2026-08-21-%E8%A1%8C%E4%B8%9A%E6%97%A5%E6%83%85%E6%8A%A5/)

**对学科网的含义**：讯飞对 G 端的主动收缩，短期可能给资源型和项目型场景留出空间；但其把重心转向标准化产品后，在精准教学、智能批阅、课堂终端与学情诊断上，对学科网的正面挤压会更稳定。

### 2. 腾讯云发布 LearnBuddy 教师助手，大厂 B 端教师工具继续加码

行业日情报记录，腾讯云在 GSE2026 发布 LearnBuddy 教师助手，围绕创新教学设计、智能备课、虚拟教研和教师主导的课堂支持做产品化落地，并启动“创新教学生态共建计划”。这是又一个面向教师端的 B 端工具信号。[查看行业日情报](https://comp.wzrong.me/industry/%E6%97%A5%E6%83%85%E6%8A%A5/2026-08-21-%E8%A1%8C%E4%B8%9A%E6%97%A5%E6%83%85%E6%8A%A5/)

**对学科网的含义**：大厂平台在教育 B 端的入口正在增多。学科网如果要守住教师端价值，不能只强调内容供给，还要把教研、备课、资源编排和课堂工具做成可接入的工作流。

### 3. GSE2026 收官成果偏向标准与教师应用，行业叙事继续前移

大会发布《全球智慧学校计划》和《人工智能教育探索丛书》8 本，聚焦智慧学校、教师专业发展、教学创新和生成式 AI 在基础教育中的应用。它们目前还是大会倡议和出版成果，但已经把行业关注点推向“学校方案 + 教师应用 + 评价体系”。[查看行业日情报](https://comp.wzrong.me/industry/%E6%97%A5%E6%83%85%E6%8A%A5/2026-08-21-%E8%A1%8C%E4%B8%9A%E6%97%A5%E6%83%85%E6%8A%A5/)

**对学科网的含义**：后续若这类倡议转成区域评价、采购或学校认证参考，学科网的产品形态会被进一步要求标准化、可交付、可度量，尤其是教研与评价环节。

## 建议关注

1. **把教师工具做成标准接入层**：围绕备课、题库、批阅、教研和学情解释，准备可给区域平台、集成商和硬件厂商直接调用的组件。
2. **盯住“标准化教育方案”的入口变化**：继续跟踪智慧学校、教师素养、AI 通识课和学情评价是否从大会倡议转成区域采购或制度口径；同时参考当日 AI 简报里的模型定价、Agent 监控和权限治理信号，把安全与成本控制纳入方案底线。[查看当日 AI 简报](https://comp.wzrong.me/ai-briefings/2026-08-21-AI%E6%AF%8F%E6%97%A5%E7%AE%80%E6%8A%A5/)
