# 学科网情报系统｜每日情报概要

**日期：2026-09-24（Asia/Shanghai）**

> 本概要只汇总截至 2026-09-24 已核实并落盘的当日产出。行业日情报主要覆盖 2026-09-23；AI 简报覆盖 2026-09-23 08:57 至 2026-09-24 09:04。未将旧内容冒充当日新增。

## 一句话判断

国家层面把教师人工智能素养和实践教学推入制度化扩围，叠加具身智能、Agent 平台化与模型降价，教育 AI 竞争重点正从“资源规模”加速转向“教学动作、上下文数据与可持续服务闭环”。

## 今日重点

### 1. “十五五”教育部署把教师 AI 素养培训与实践教学推向全国化

教育部公开发布会信息显示，教师人工智能素养全覆盖培训、每周至少半天校外实践教学、国情研学制度等被纳入未来五年教育部署；国家中小学智慧教育平台科技教育板块已有 3000 多条免费资源，并继续推进示范课程与教学案例建设。

**对学科网的含义：**教师 AI 培训、教研服务和实践/研学课程的区域化产品机会更明确，但免费优质资源供给也抬高了行业基线。学科网需要把内容优势进一步转化为课标对齐、学段适配、教师能力提升和学习成果评价能力，而不能只强调资源数量。

### 2. 教育 AI 的竞争单位从“内容”转向“教学动作与实践标准”

北京海淀将全学段 AI 通识课、具身智能实践和区级实践标准放入科学教育推进框架；行业案例同时提出，AI 教育竞争正从内容分发转向对学生状态的理解和教学动作的动态规划。

**对学科网的含义：**产品差异化需要从“提供什么资源”升级为“如何将资源组织成可执行、可评价的教学流程”。备课、课堂、作业、讲评、学情分析和实践课程之间的上下文衔接，将比单点内容数量更能形成长期壁垒。

### 3. 基座价格下探与 Agent 平台化并行，模型本身更难成为教育产品护城河

AI 简报记录了 OpenAI GPT-6 Sol/Luna 与 Anthropic Claude Opus 5.5 的价格和缓存成本变化，以及阿里千问 Agent Studio 将模型、知识数据接入、托管运行和工具调用整合为企业级服务；同时，DeepSeek 对生产级 Agent 训练沙盒及 reward hacking 的披露，提醒行业重视安全隔离和可控运行。

**对学科网的含义：**模型调用成本下降有利于教育 AI 产品扩大使用，但通用 Agent 平台也降低了学校接入自有资料、自建智能体的门槛。学科网应优先沉淀自有教研方法论、题库与学情上下文，并建立模型路由、成本、质量和安全的场景化评测体系，避免价值被压缩为单纯内容或语料供给。

## 建议关注

1. **教师 AI 素养与实践教学产品化：**围绕教师培训课程包、AI 应用评价、实践/研学课程模板和成果评价，梳理可由区域采购或学校教研直接采用的组合形态。
2. **上下文数据与模型工程治理：**盘点 AI 小博士、备课、课堂、作业、组卷、讲评和学情分析中的自有数据入口，明确哪些能力必须掌握在学科网侧，哪些能力可通过 Agent 平台或模型服务接入。
